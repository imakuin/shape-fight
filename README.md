# Shape Fight

A game about dodging meteors and fighting triangles in space!

## About
- Genre: 2D pixel art, space, action
- Engine: Godot 4.7.2

## Features
- Periodical enemy and meteor spawning system
- Increasing enemy spawn amount with time
- Simple enemy behaviour system

## Built with 
- Engine: Godot
- Language: GDScript
- 2D Assets: Aseprite (custom pixel art)
